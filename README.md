#  Rug House
Spring Boot를 활용한 러그 쇼핑몰 사이트

## 프로젝트 소개
방문자가 상품 정보를 확인하고 회원 가입 할 수 있는 기초적인 구조의 러그 판매 쇼핑 사이트를 구현하고, WAS 배포를 경험하는 프로젝트 입니다.

회원 : 상품 조회 , 회원 정보 수정, 탈퇴 가능
관리자 : 상품 추가, 회원 정보 관리, 상품 정보 관리

개발 기간 : 2026.06.22 ~ 2026.06.29

## 개발 환경
- Java
- Spring Boot
- Spring MVC
- MyBatis
- MySQL
- Oracle
- HTML / CSS / JavaScript
- Eclipse STS
- Apache Tomcat 10.1.12

## 주요 기능
### 회원
- 회원 가입
- 로그인 / 로그아웃
- 회원 정보 조회 및 수정
- 회원 탈퇴

### 상품
- 상품 목록 조회
- 카테고리별 상품 조회
- 상품 등록
- 상품 수정
- 상품 삭제

### 관리자
- 회원 정보 관리
- 상품 정보 관리

## 프로젝트 구성
```text
views
├── admin
├── guest
├── member
└── product
```
